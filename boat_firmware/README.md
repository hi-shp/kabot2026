# 아두이노 운용 기본값

2026-10-30 현재 설정은 `kabot_actuator/board_config.h`입니다. **ESC 정지·초기화 PWM은 사용자 요청에 따라 양쪽 1480µs입니다. 젯슨 논리 명령 중립은 1500입니다.** 아래 이전 기록의 ESC 1500µs는 이 설정으로 대체합니다.

| 기능 | 수신기 채널 → UNO 입력 | UNO ESC 출력 |
|---|---|---|
| 좌현 전진·후진 | CH2 → D2 | D9, RC 반전 적용 / AUTO 반전 적용 |
| 우현 전진·후진 | CH3 → D3 | D10, RC 반전 미적용 / AUTO 반전 적용 |
| RC/AUTO 전환 | **CH5 → D4** | 해당 없음 |

모드의 ‘5’는 **수신기 채널 번호**입니다. UNO D5는 사용하지 않습니다. RC 출력 크기는 중립 구간에서 0, 구간 밖에서 `400u²`(정규화 입력 u=0~1)로 처리합니다. 초기 출력 보정 없이 0부터 시작하며 끝점 최대 400을 유지하고 좌우·전후에 동일 적용합니다.

- RC 입력 중심은 현재 놓아둔 위치의 실측값 **양쪽 1496µs**입니다(65개씩 관측, 1488~1500µs). 젯슨 명령 중립·ESC 정지 출력은 **1500µs**를 유지합니다.
- 브링업 USB 연결 때 UNO를 DTR로 한 번 재시작하고 양쪽 ESC에 1500µs를 **7초** 출력합니다. [제조사 아두이노 예제](https://bluerobotics.com/learn/basicesc-r3-example-code-for-arduino/)의 초기화 순서를 적용했습니다. 현재 맞는 AUTO 전후 방향은 유지합니다.
- 수신기 PWM 연결이 새로 확인될 때도 양쪽 ESC를 중립 7초로 초기화합니다. RC 단독 운용에는 젯슨 브링업이 필요 없습니다. RC→AUTO 전환은 20ms 중립을 출력하고 새 AUTO 무장·명령을 즉시 수락합니다. AUTO→RC는 RC가 우선합니다.
- 이전 양쪽 회전 확인은 이미 RC로 조작한 뒤였습니다. ESC 전원 직후 RC 선행 조작 없는 초기화·초기화음은 미확인입니다.
- RC 중립 범위는 양쪽 **1446~1546µs**입니다. 입력 한계 1000~2000µs는 설정값이며 이번에 끝점 실측은 하지 않았습니다. 각 중심에서 공통으로 가능한 대칭 폭 **±496µs** 전체에 같은 2차 곡선을 적용합니다. 별도 끝점 여유를 빼지 않으며 유효 입력 끝점은 1000/1992µs, 출력은 1100/1900µs입니다. 좌우·전후 방향은 유지합니다.
- CH5/D4가 **1700µs 초과이고 좌우 PWM도 유효하면 RC**입니다. 그 외(수신기 없음·유효 RC 선택 없음)는 AUTO입니다. 스위치 위치는 교환하지 않았습니다.
- 젯슨은 RC/AUTO 상태에 상관없이 시험 명령을 계속 보냅니다. RC일 때 무시하고 AUTO일 때 반영하는 판단은 아두이노에서만 합니다. 부팅·브리지 재연결·수신기 신규 연결 때 ESC 중립을 7초 유지합니다.
- RC→AUTO 전환 시 기존 RC 출력·무장을 폐기합니다. 3초 대기는 없으며 새 무장·추진 명령만 반영합니다.
- AUTO→RC에서는 기존 AUTO 명령을 폐기하고 현재 조종기 입력을 따릅니다.
- 필요한 RC PWM이 끊기면 최대 100ms 안에 감지해 중립으로 보내고, AUTO 명령이 400ms 동안 끊겨도 중립으로 갑니다.
- 시험·프록시·브리지의 Ctrl+C/SIGTERM/정상 종료는 정지 명령과 응답 확인을 거칩니다. 정지 후 RC는 양쪽 스틱을 중립에 0.5초 두면 자동 복귀하고, AUTO는 새 실행의 무장이 필요합니다. 별도 잠금 해제 명령은 필요 없습니다.
- ESC 모델은 Basic ESC 500입니다. D9/D10은 Timer1 하드웨어 PWM 400Hz로 구동합니다(제조사 허용 50~500Hz). 중립 1500µs·초기화 7초이며, 초기화 중 무장·추진 명령은 거절합니다. 정상 기동은 보드 자체 PWM 관측과 구분해 확인해야 합니다.

젯슨 명령은 기존 **1500=중립, 1100~1900 범위**를 유지합니다. 아두이노가 좌우별 방향으로 변환합니다. 송신기를 꺼도 수신기가 유효 PWM을 계속 보내면 이 입력만으로 무선 단절 여부는 판별할 수 없습니다.

이전 기준 펌웨어 백업: 젯슨 `/home/isv/code_backups/arduino-rc1470-direction-only-HHfr60dk/`의 `source/`와 `new_firmware.hex`. 전원이 공급되면 펌웨어는 계속 실행됩니다. 좌우 D9/D10은 유지하며, 이번 방향 수정은 퍼센트 시험을 포함한 AUTO 양쪽 출력에만 적용합니다. RC 방향은 별도 설정으로 유지합니다.
