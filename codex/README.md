# 문서·백업·로컬 도구

현재 운용 소스는 저장소 최상위의 젯슨 패키지들과 `firmware/kabot_actuator/`입니다. 이 폴더에는 작업 자료와 보존용 사본을 모았습니다. `COLCON_IGNORE`로 ROS 패키지 검색에서 제외합니다.

| 경로 | 내용 |
|---|---|
| [docs/](docs/BOAT_BASELINE_2026-10-30.md) | 운용 기준·주요 명령·조사 기록·소스 목록 |
| [PROJECT_STRUCTURE.md](PROJECT_STRUCTURE.md) | 저장소와 젯슨의 경로 대응 |
| `scripts/` | cb 설정·소스 수집·수동 종료 도구 |
| `tests/` | 셸 함수와 프로세스 종료 검사 |
| [firmware/](firmware/README.md) | 펌웨어 설명·빌드/업로드 도구·검사 코드 |
| `deploy/` | 이전 배포용 사본 |
| [backups/](backups/README.md) | 2026-10-29 젯슨 소스 백업 |
| `로컬보관/` | 이번 정리 직전의 로컬 코드·문서·이미지 |
| [레거시코드/](레거시코드/README.md) | 기존 겨울 최종 코드 원본 |

현재 소스 비교 목록은 [JETSON_SOURCE_MANIFEST.json](docs/JETSON_SOURCE_MANIFEST.json)에 있습니다. 이전 기준 태그와 날짜별 백업은 당시 경로를 보존합니다.
