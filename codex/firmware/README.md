# 아두이노 설정

2026-10-30 사용자가 RC/AUTO 좌우 전후진과 모드 전환을 확인한 설정입니다. 실행 명령은 [정상 운용 기준](../docs/BOAT_BASELINE_2026-10-30.md)에 있습니다.

## 배선과 기본값

| 항목 | 설정 |
|---|---|
| 보드 / ESC | UNO R3 / Blue Robotics Basic ESC 500 |
| 좌현 입력 / 출력 | 수신기 CH2 → UNO D2 / UNO D9 → 좌현 ESC |
| 우현 입력 / 출력 | 수신기 CH3 → UNO D3 / UNO D10 → 우현 ESC |
| 모드 입력 | 수신기 CH5 → UNO D4 |
| RC 선택 | D4 >1700µs, 세 입력 모두 유효·최신 |
| RC 입력 중심 / 중립 범위 | 양쪽 1496µs / 1446~1546µs |
| RC 입력 대칭 폭 | ±496µs, 공통 유효 끝점 1000/1992µs |
| RC 방향 반전 | 좌현 true, 우현 false |
| AUTO 방향 반전 | 좌현 true, 우현 true |
| ROS/시리얼 명령 | 1100=최대 후진, 1500=정지, 1900=최대 직진 |
| ESC 정지·초기화 출력 | 양쪽 1480µs |
| 출력 범위 / 주파수 | 1100~1900µs / Timer1 하드웨어 PWM 400Hz |
| 초기화 / RC→AUTO 중립 | 7초 / 20ms |
| AUTO 명령 감시 / MCU watchdog | 400ms / 250ms |
| EMO | 외부 스위치로 ESC 전원 차단, UNO 감지 입력 없음(`ESTOP_PIN=-1`) |

수신기 채널 번호와 UNO 핀 번호를 구분합니다. 모드 신호는 **CH5 → D4**입니다.

현재 소스는 저장소 최상위 `firmware/kabot_actuator/`에 있습니다. 빌드 설정은 [`board_config.h`](../../firmware/kabot_actuator/board_config.h)를 기준으로 합니다. `actuators.json`은 참고 사본이고, `generate_config.py`는 수동 실행 도구입니다.

## 출력과 모드 전환

사용자가 말하는 **1000/1500/2000**은 ROS 명령의 **1100/1500/1900**으로 변환합니다. 현재 서비스의 입력 범위는 1100~1900이며, 퍼센트는 PWM 명령 폭의 비율입니다.

RC 좌우는 각각 중립 구간 밖에서 `round(400u²)` 곡선을 따릅니다. 출력은 0부터 부드럽게 증가해 끝점에서 최대에 도달합니다. RC와 AUTO의 방향 보정값은 따로 관리합니다.

UNO는 전원이 들어오면 펌웨어를 실행합니다. 부팅·USB 브리지 재연결·수신기 신규 연결 때 양쪽에 1480µs를 7초간 보내 ESC를 초기화합니다. RC 단독 조종은 UNO 전원과 수신기 연결로 동작합니다. 초기화 중 AUTO A/C 요청은 거절되고, 젯슨 송신 노드는 재시도합니다.

RC→AUTO는 기존 출력을 해제하고 20ms 동안 중립을 유지한 뒤 새 명령을 반영합니다. AUTO→RC는 조종기 입력을 우선합니다. 수신기 PWM이 끊기면 기존 명령을 해제하고 AUTO로 전환합니다. 수신기가 단절 후에도 PWM을 계속 내보내는 경우에는 수신기 failsafe 설정도 함께 확인해야 합니다.

## 통신과 업로드

시리얼 속도는 115200baud, 명령 형식은 `K1,seq,operation,left,right*CRC16`입니다.

| 명령 | 동작 |
|---|---|
| I | 초기화 |
| A / D | AUTO 무장 / 해제 |
| C | 좌우 출력 지정 |
| S | 중립 정지 |
| R | 이전 인터페이스와의 호환용 해제 요청 |

S 이후 RC는 양쪽 스틱을 중립에 0.5초 두면 복귀합니다. 계속 송신 중인 AUTO 노드는 새 무장 명령으로 출력을 재개할 수 있습니다.

[`jetson_upload.sh`](jetson_upload.sh)는 젯슨에서 실행합니다. 기본 동작은 빌드이며, `--flash`를 붙이면 포트 점유 확인 → 기존 flash 이중 읽기·EEPROM 백업 → 업로드·검증을 수행합니다. 업로드 시 UNO가 재시작됩니다. 경로와 실행 순서는 정상 운용 기준을 참고합니다.

저장소에서 빌드할 때는 젯슨에서 `bash codex/firmware/jetson_upload.sh --build-only`를 실행합니다. 현재 `~/boat_firmware`의 기존 배포 경로도 계속 지원합니다.
