3D 상대 맵 · 선수 0°

수신 대기

시작 선수 방향이 X+·0°입니다. 매 스캔 현재 선수 기준 전방 180°(좌우 ±90°), 수평 반경 0.1–2m만 사용하며 높이는 제한하지 않습니다. 기본 시점: 선수 위·좌현 왼쪽·우현 오른쪽. 드래그 회전 · 휠 확대/축소.

라이다 원점 · GPS X=−0.40m · 색상은 실제 Z 높이 · 누적 맵 범위는 이동에 따라 넓어집니다.

지도를 클릭해 호핑 위치를 지정하세요.

맵 생성 → 맵 생성 종료 → 맵 저장 → 맵 불러오기. 불러오기 전 2D에는 현재 위치만 표시합니다.
