# Arduino UNO R3 추진기 제어

배선: RC 수신기 첫 채널 D3, 둘째 채널 D2, RC/AUTO 전환 PWM D4; ESC 좌현 D9, 우현 D10. D4의 약 2000 µs는 RC 모드로 실측했고, 반대쪽 AUTO 위치는 아직 실측하지 않았습니다. 기존 보드 플래시에서 확인한 RC 혼합 계산과 중심값(첫 채널 1485 µs, 둘째 채널 1490 µs)을 `kabot_actuator`에 반영했습니다. 소스 원본은 보드에 없었으므로 컴파일된 기존 코드의 동작을 역분석했습니다.

기존 플래시는 업로드 전에 젯슨의 `/home/isv/code_backups/arduino-uno-before-autonomy-20261029/`에 두 번 읽어 동일한 바이너리로 보관했습니다. 원본 플래시 SHA-256: `493c1b59f0269dc2387b39d5693cd5b79eb6be63a2181e03d82696af50f2b346`. 로컬 사본은 `C:\Users\Park\Documents\JetsonWaterTrial-20261029\arduino-original-backup\flash_read1.bin`입니다. EEPROM도 젯슨 백업 폴더에 보관했습니다. 백업 바이너리는 Git에 올리지 않았습니다.

보드에는 D4 모드 채널과 기존 RC 혼합을 적용한 펌웨어를 업로드하고 `avrdude` 검증을 마쳤습니다. RC 모드에서 수신 펄스와 D9/D10 중립 펄스를 확인했습니다. 모터 전원을 분리한 상태였으므로 ESC 입력·스러스터 회전은 검증하지 않았습니다. RC 스위치를 AUTO로 전환하지 않았으므로 실제 보드의 AUTO 명령 수락·시간 초과 정지도 아직 검증하지 않았습니다.

ROS 브리지는 시작할 때 자율운항 무장 해제 명령만 보냅니다. AUTO 위치에서 조종기 중립을 확인한 뒤 `/actuators/arm`에 `true`를 보내야 명령을 받으며, `false`는 자율운항 명령을 해제합니다. 한쪽 추진기 서비스 호출만으로는 출력하지 않고, 좌우 서비스의 동시 요청을 한 프레임으로 묶습니다. 명령 유효 범위는 좌우 각각 1400~1600 µs, MCU 명령 만료는 400 ms입니다. 물리 비상정지 배선과 배터리 전압 입력은 아직 확인되지 않았습니다. 자율운항 경로 계획과 MPC는 젯슨에서 실행합니다.
